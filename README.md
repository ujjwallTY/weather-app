# 🌦️ Weather App

A responsive weather application built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🔍 Search weather by city
- 📍 Get weather using current location
- 🌡️ Temperature
- 💧 Humidity
- 🌬️ Wind Speed
- ☁️ Cloud Percentage
- 🕒 Local Time
- 🌤️ Weather Icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- WeatherAPI
